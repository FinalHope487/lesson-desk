# 講義桌

講義桌是用來閱讀教材、加入段落註解和作答的靜態網頁，支援繁體中文介面。

## 開始使用

1. 開啟 [線上講義桌](https://finalhope487.github.io/lesson-desk/)，或下載儲存庫後在瀏覽器開啟 `index.html`。
2. 從課程資料庫選讀 103 篇高中數學、物理與化學教材，或選「匯入對話」載入自己的 JSON、Markdown 或純文字檔，可一次選多份。
3. 點選教材段落加入註解或引導問題。按「匯出含註解的 JSON」保存，日後可重新匯入。

網站不需要安裝套件或設定金鑰。匯入的檔案在瀏覽器中處理。

## GitHub Pages

在儲存庫的 Settings → Pages，選擇 Deploy from a branch，來源設為 `main` 的 `/(root)`，再儲存。`index.html` 內含公開教材資料。
