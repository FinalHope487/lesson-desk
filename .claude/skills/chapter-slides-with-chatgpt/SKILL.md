# 章節教材

三種用途均預設採用直式頁面，以平板整頁閱讀為主。建立 PPTX 時即設定頁面方向，從最終 PPTX 匯出的 PDF 沿用相同尺寸與方向。使用者指定橫式時依其要求。

1. 讀當次要求與來源，確認章節邊界、用途、先備能力及已指定的答案揭露限制。預設繁體中文；使用者已說明的事項直接沿用。只有缺少的資訊會改變內容時才提問。使用者若同時要速讀和練習，可以一條速讀主線搭配題目區。
2. 建立內部對照表。逐節記下「來源位置｜學生應能解釋什麼｜輔助內容｜教材頁」，逐題及小題記下「題號與來源頁｜需要判斷什麼｜第一步及理由｜後續所需知識｜教學頁與練習頁」。納入圖中問題、例題及章末題。看不清的圖、條件、單位或小題先查相鄰頁，仍缺資料就標明位置請使用者補件。別憑答案反推原題。
3. 依用途讀一份指南：[初學自學講義](references/beginner.md)、[考前速讀](references/review.md)、[題型訓練](references/practice.md)。混合需求可合讀。採用 [概念、例題與版型](references/teaching.md) 設計內容。
4. 讓讀者只靠可見頁面就能走完推理。以來源位置標示原題與改編例；預設保留範圍內每一原題及小題的完整條件、必要圖表及原編號。可選部分作示範，其餘留作獨立練習。若原題須保留給學生首做，用條件不同的例題示範；提示與答案依使用者要求揭露。另冊詳解只在指定時製作。
5. 按 [製作與驗收](references/delivery.md) 產出及檢查每章的兩份檔案。工作對照表留作核對，交付時提供可直接開啟的 PPTX、PDF 連結及實際查核結果。
