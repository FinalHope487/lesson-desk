# 題型訓練

用「要判斷什麼才知道第一步」分題。先在同型題中找出共同線索，再挑外觀相近、起手卻不同的一對，說明哪個條件能區分兩者。若來源只有一種題型，可用條件變化帶出適用界線，清楚標示自編。

每一組先用一道完整示範，讓讀者看到怎麼讀條件、選第一步、完成解題並檢查結果。接著出一道只問「你先做什麼？哪句題意支持你？」的題，再安排完整作答。末段打散題型、移除方法標籤，讓學生自己辨識；已被示範過的原題可用不同條件的練習檢驗遷移。

回饋應定位錯在讀取條件、選方法或執行哪一步。例如「你算出的是總路程；題目要的是從起點到終點的位置改變。先在圖上標起點和終點，再決定正方向。」保留無提示的首次作答機會，必要提示放後頁供選讀。
