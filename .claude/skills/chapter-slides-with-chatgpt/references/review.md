# 考前速讀

先寫下學生讀完必須能回答的章節問題，再把相依的問題排成最短可讀順序。每個教學重點要有足以讓學生重述的解釋、適用條件及必要推理。輔助內容縮成讀者能講出大意的一句話、一個圖例或簡短註解；只要某小題用到其中一個細節，就把該細節移回教學主線。

「八成」用來決定在哪裡少花時間。優先合併重複演算、縮短背景敘事，把次要推導移到按需翻閱的頁面。若證明本身就是教學重點或原題要求，保留足以重建證明的理由。速讀路線標出必讀頁與回查頁；估時若有提供，分開計算閱讀與做題。

從每一道原題及小題回查教學頁。遮住解答，只用教材及約定的先備知識，逐題推到結論。兩題即使使用同一公式，只要選式條件、資料轉換或收尾判斷不同，就要查那個差異是否教過。補一個判斷句或短例往往比再放一整份詳解省時。

安排一條能從頭到尾獨立做原題的路線。課本已有詳解的例題也先保留獨立題面，詳解放後頁；必要時以自編同型例帶路。把「題號 → 回查頁」索引放在練習區之後，以免頁名先透露解法。
