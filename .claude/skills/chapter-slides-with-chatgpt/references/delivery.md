# 製作與驗收

在最終 PPTX 與 PDF 的整頁檢視中，按預定平板閱讀大小逐頁確認正文、圖說、題號與章標題下的來源小字皆可辨讀。核對兩檔的頁面尺寸及方向，並逐章翻回原講義查驗每一組章節編號與來源頁碼。頁尾教材頁碼應與實際閱讀順序一致。

1. 使用環境可用的簡報工具建立 PPTX。標題、正文、表格與自製圖解用原生可編輯物件；公式使用可編輯方程式或可直接修改且能正確呈現的文字。原始照片、掃描圖可嵌圖，另放可編輯圖說。把需要學生知道的資訊放在頁面，PDF 也能讀到。頁面擁擠時沿著推理拆頁。
2. 在最後一次存檔後，以 PowerPoint 匯出 PDF，或在有 LibreOffice 的環境執行 `soffice --headless --convert-to pdf --outdir <輸出目錄> <最終簡報.pptx>`（實際路徑含空格時加引號）。以相同章名與用途命名兩檔。若匯出失敗，保留實際錯誤並嘗試可用的另一個匯出器；缺少可用工具時標示缺件。
3. 對照來源逐節及逐小題核對。挑一個新記號，遮住定義，確認教材提供的情境足以讓人說出其用途。遮住例題解答，從題幹指出選擇第一步的證據，再獨立完成推理並核對結果。若碰到只靠答案才猜得到的跳步，在首次用到處補上理由。不得將作者走查記成學生實測。
4. 開啟最終兩檔，核對投影片數、PDF 頁數、順序與各頁標題。抽選正文、表格、公式或圖形中實際用到的物件，確認可以選取修改；用副本試改以免更動交付檔。逐頁查看投影片與 PDF 的渲染結果，放大檢查中文缺字、上下標、單位、遮擋、斷行、裁切與原題圖表。修正 PPTX 後重新匯出 PDF，重查受影響頁與頁碼索引。
5. 交付時列出兩個檔案連結、用途、章節與實際驗證範圍。若資料缺失或有步驟未執行，具體寫出受影響的題號、頁面或檔案。
